## 2024-05-28 - Missing Architecture Requirements
**Vulnerability:** The recent implementation of the cinematic pipeline introduced a major functional regression by removing the `localFileToDataUri` helper from `app/api/try-on/route.ts`. This breaks the try-on functionality for pre-selected garments that use local relative paths, as the Replicate API requires a public HTTP URL or a Data URI. Furthermore, the implementation completely omitted several core requirements: the 'Hyper-Zoom' rendering engine (texture sharpness), the Accessory Layer (bags, rings, etc.), and the Global Brand Library database mapping.
**Learning:** When refactoring existing API routes to proxy to a new backend, ensure that critical data transformation logic (like converting local files to Data URIs) is either preserved in the proxy layer or successfully migrated to the new backend. Additionally, ensure all explicit architectural requirements (like specific visual features or database mappings) are addressed in the implementation plan.
**Prevention:** Implement rigorous testing for existing functionality (like trying on default local assets) after architectural changes. Ensure thorough review of the original requirements document before considering a feature implementation complete.
