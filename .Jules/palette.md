## 2024-05-24 - Hidden Until Needed UI Pattern
**Learning:** To maintain a pure and minimalist main screen, secondary features (like member access and support guides) must avoid cluttering the primary view and disrupting the user immersion.
**Action:** Implemented the "Hidden until needed" philosophy by replacing static buttons with discreet, corner-anchored icon-only triggers (using material symbols) that open high-fidelity, framer-motion powered slide-out drawers and modals. Added `aria-label` attributes to these icon-only triggers for accessibility.
