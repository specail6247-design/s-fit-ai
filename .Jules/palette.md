## 2024-05-24 - Accessibility for Icon-only Buttons in Immersive Components
**Learning:** In full-screen immersive components (like `LuxuryGarmentDetail.tsx` or `ARLiveFitting.tsx`), icon-only buttons that rely on Google Material Symbols (`material-symbols-outlined`) spans for visuals are frequently used to minimize UI clutter. However, without explicit text content or `aria-label` attributes, these buttons are inaccessible to screen readers, which may announce them as unlabelled buttons or read the raw ligature string (e.g., "zoom in").
**Action:** When adding or modifying icon-only buttons that rely on `material-symbols-outlined` spans for visuals, explicitly include an `aria-label` attribute on the `<button>` or `<Link>` element to ensure screen reader accessibility. This pattern should be applied consistently across all immersive and luxury views.
