## 2024-05-15 - Material Symbols Icon-Only Buttons
**Learning:** In the luxury interfaces (`LuxuryGarmentDetail`, `ARLiveFitting`), there's a strong pattern of using Google Material Symbols within otherwise empty `<button>` or `<Link>` tags (e.g., `<button><span className="material-symbols-outlined">zoom_in</span></button>`). Because the text inside the span is visually rendered as an icon, these elements are effectively icon-only to screen readers and lack accessible names. Furthermore, without explicit focus styles, keyboard navigation through these interactive 3D overlays is visually untraceable.
**Action:** When adding or modifying icon-only buttons that rely on `material-symbols-outlined` spans, always explicitly include an `aria-label` attribute on the interactive element (`<button>` or `<Link>`) describing its function. Additionally, append `focus-visible:ring-2 outline-none` (using the appropriate theme color, e.g., `focus-visible:ring-[#ecab13]` for luxury mode) to ensure keyboard navigation visibility.
