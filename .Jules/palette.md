## 2024-09-09 - Icon Button Accessibility\n**Learning:** When using Material Symbols ligatures inside interactive elements (buttons, links) in this React codebase, screen readers can accidentally announce the ligature text (e.g. "arrow_back").\n**Action:** Always add `aria-hidden="true"` to the icon `<span>` and a descriptive `aria-label` to the parent `<button>` or `<Link>` element.
