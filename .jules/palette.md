## 2025-01-22 - Improved Accessibility for Material Symbols Icon-Only Buttons
**Learning:** Found that icon-only buttons utilizing text-based icon fonts (like Material Symbols) were missing `aria-label`s on their parent interactive elements and the literal text characters weren't hidden using `aria-hidden="true"`, causing screen readers to announce literal text strings (like 'arrow_back' or 'info') instead of meaningful actions. Some interactive elements like "back" were structured as non-semantic `<div>` tags instead of `<button>`s, breaking keyboard accessibility.
**Action:** Always wrap text-based icon font characters (e.g., `<span aria-hidden="true">icon_name</span>`) and supply an explicit `aria-label` on the parent semantic interactive element (`<button>`, `<Link>`, etc.). Ensure all custom interactive components utilize proper semantic HTML elements to guarantee native keyboard navigation support and focus management.
