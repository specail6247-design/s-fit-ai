## 2026-09-21 - AuthButton Modal Accessibility
**Learning:** When improving accessibility for React form components that rely solely on visually styled placeholders (like login modals), explicitly adding aria-label attributes to the inputs, aria-busy={loading} to the submit button, and focus-visible utilities ensures proper screen reader announcements and keyboard navigation.
**Action:** Use these accessibility techniques for custom modals in Next.js instead of just relying on placeholders.
