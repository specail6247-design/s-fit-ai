## 2026-01-22 - Escaping Apostrophes in JSX
**Learning:** Next.js throws build errors (`react/no-unescaped-entities`) when unescaped apostrophes exist in JSX (e.g. `S_FIT AI's`).
**Action:** Always use HTML entities like `&apos;` for apostrophes when writing JSX.

## 2026-01-22 - Building Trust through UI
**Learning:** Adding explicit legal terms (Privacy Policy/Terms of Service) and a data safety indicator directly next to sensitive inputs (like photo uploads) significantly increases user trust.
**Action:** Always include a clearly visible Data Safety Badge near sensitive data collection components. Provide easily accessible Legal Modals via a global footer layout rather than hiding them deep in settings.
