
## 2024-05-01 - [Path Traversal and SSRF Vulnerabilities in API Routes]
**Vulnerability:** The `app/api/try-on/route.ts` API route accepted an arbitrary `garmentImageUrl` path which was passed to `path.join()` alongside `process.cwd()` without verifying the final absolute path resided within the public directory, leading to a Path Traversal vulnerability (e.g., retrieving system files). Furthermore, `app/api/try-on/route.ts`, `app/api/cinematic-try-on/route.ts`, and `app/api/runway-motion/route.ts` accepted external image URLs without validating the protocol schema, enabling Server-Side Request Forgery (SSRF) attacks or malicious protocol injections.
**Learning:** Next.js API routes that proxy requests or process user-provided URLs/paths are highly susceptible to SSRF and Traversal if bounds and prefixes aren't strictly validated. `path.join` does not sanitize against `../` escaping unless the resultant path is strictly verified against an allowed base directory.
**Prevention:** Implement an `isValidExternalUrl` utility that strictly enforces allowed protocols (`http://`, `https://`, `data:image/`). For local file access, always use `path.resolve` and verify the resulting absolute path explicitly `startsWith` the intended base directory (plus a path separator).
