## 2025-04-02 - [Exposed API Key via dangerouslyAllowBrowser]
**Vulnerability:** The OpenAI API client was initialized with `dangerouslyAllowBrowser: true` and the `NEXT_PUBLIC_OPENAI_API_KEY` environment variable in a utility file (`lib/visionService.ts`) imported by a Client Component (`DigitalTwinMode.tsx`). This exposed the secret API credentials to the browser, allowing potential attackers to steal and misuse the API key.
**Learning:** Next.js allows utility functions to be imported on both the server and the client. When a utility file initializing a server-side SDK is imported into a Client Component (e.g., one with `'use client'`), that code executes in the user's browser. Enabling `dangerouslyAllowBrowser` explicitly bypasses the SDK's built-in safeguard against this, exposing the key.
**Prevention:** Avoid using `dangerouslyAllowBrowser: true` unless absolutely necessary and securely proxied. To safely instantiate server-only SDKs in utility files that might be imported on the client, wrap the initialization in a function that checks the environment (e.g., `typeof window !== 'undefined'`) and returns `null` or throws an error when executing on the client.
