## 2026-08-03 - Fix Path Traversal in Virtual Try-On API
**Vulnerability:** The `localFileToDataUri` function in `app/api/try-on/route.ts` used `path.join` with user-supplied input (`garmentImageUrl`) to construct an absolute file path. It did not verify that the resulting path remained within the intended `public` directory, allowing directory traversal attacks (e.g., passing `/../../../etc/passwd` to read arbitrary system files).
**Learning:** Using `path.join` or `path.resolve` with untrusted input is dangerous even if the input is prepended with a base directory. Path traversal characters (`../`) can still cause the resolved path to escape the base directory.
**Prevention:** Always check that the final, resolved absolute path starts with the base directory plus a path separator (e.g., `absolutePath.startsWith(publicDir + path.sep)`). Never use `absolutePath.startsWith(publicDir)` as it allows partial path bypass (e.g., `/app/public_secrets` matching `/app/public`).
