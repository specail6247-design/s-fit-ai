## 2024-11-20 - [Path Traversal in Try-On API]
**Vulnerability:** A path traversal vulnerability existed in `app/api/try-on/route.ts` where user-controlled paths (`localPath`) were concatenated using `path.join(process.cwd(), 'public', relativePath)` without strict directory bounds validation. An attacker could potentially supply a payload like `/../../../etc/passwd` to read arbitrary local files outside the `public/` directory via the Next.js API route because `fs.readFileSync` was called directly on the user-supplied path.
**Learning:** `path.join` resolves relative segments like `..` but does not prevent the resulting path from escaping the intended base directory. If a user provides enough `../` segments, the resulting absolute path will fall outside the intended boundaries.
**Prevention:** To prevent path traversal when handling local file paths, always use `path.resolve` to get the absolute path and strictly verify that it starts with the intended base directory (e.g., `absolutePath.startsWith(publicDir + path.sep)`) before performing asynchronous or synchronous file I/O operations.
