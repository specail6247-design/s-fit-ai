## 2025-03-06 - Path Traversal Vulnerability in `localFileToDataUri`
**Vulnerability:** A path traversal vulnerability existed in `app/api/try-on/route.ts` where `path.join` was used to resolve local file paths provided by the user via API request body. Malicious users could supply paths like `/../../../etc/passwd` to read arbitrary files from the server's filesystem since `path.join` does not prevent directory traversal.
**Learning:** `path.join` combined with user input directly allows traversing up directories using `..`. In Node.js/Next.js backend functions, relying on `path.join` to access files in specific directories (like the `public` directory) is insecure if the input path is user-controlled.
**Prevention:** Avoid `path.join` when reading files based on user input. Use `path.resolve` to determine the absolute target path, and explicitly validate that the resolved path strictly starts with the intended base directory (including the trailing separator, e.g., `if (!absolutePath.startsWith(publicDir + path.sep)) { ... }`) before performing any file operations.
