## 2025-02-20 - Path Traversal Vulnerability in Local File Access
**Vulnerability:** Found a critical path traversal vulnerability in `app/api/try-on/route.ts` where unsanitized user input was used in `path.join(process.cwd(), 'public', relativePath)` to read files. This allowed malicious payloads like `../../etc/passwd` to be read via `fs.readFileSync` because `path.join` normalizes the traversal but does not confine it to the target directory.
**Learning:** `path.join` is insufficient for preventing path traversal attacks when dealing with user-supplied paths, as it resolves `..` segments regardless of the base directory's boundaries. The application's architecture was surprisingly susceptible to arbitrary file reads because local media files were converted to data URIs directly via server-side file reads without strict boundary enforcement.
**Prevention:** Always use `path.resolve` combined with a strict prefix check using `path.sep` (e.g., `absolutePath.startsWith(baseDir + path.sep)`) to ensure the normalized path strictly resides within the intended directory boundaries.
