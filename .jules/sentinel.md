## 2024-05-24 - API Route Path Traversal
**Vulnerability:** A path traversal vulnerability existed in the `app/api/try-on/route.ts` API route when handling local file paths. The `localFileToDataUri` function accepted a user-provided `localPath` parameter, stripped the leading slash, and joined it with the `public` directory. Because the path wasn't sanitized, it was possible to pass payloads like `/../.env`, traversing out of the expected directory and reading arbitrary files on the system using `fs.readFileSync()`.
**Learning:** Using `path.join` with user-supplied paths without additional validation is insecure, as `path.join` resolves `../` tokens relative to the root instead of validating against an expected directory boundary.
**Prevention:** To prevent path traversal vulnerabilities when reading local files in Next.js API routes, always use `path.resolve` to get the absolute path, and verify that the absolute path string starts with the intended base directory (e.g., `absolutePath.startsWith(publicDir + path.sep)`). Additionally, switch to using async methods like `fs.promises.readFile` for better performance and non-blocking API handlers.
