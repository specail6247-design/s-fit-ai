## 2025-03-01 - [CRITICAL] Path Traversal in Try-On API
**Vulnerability:** The Next.js API route `/api/try-on` was vulnerable to path traversal. The `localFileToDataUri` function accepted a `garmentImageUrl` parameter, resolved it to a local file path using `path.join(process.cwd(), 'public', relativePath)`, and read the file to a Data URI. Due to the lack of path traversal sanitation, an attacker could supply `../../../../etc/passwd` to read arbitrary system files.
**Learning:** `path.join` does not prevent path traversal components (`../`) from resolving outside the intended directory. Next.js API endpoints that read local files must strictly validate the resolved absolute path.
**Prevention:** Always use `path.resolve` to resolve absolute paths and verify that the resulting absolute path explicitly starts with the intended base directory plus a path separator (`baseDir + path.sep`), or exactly matches the base directory, before calling `fs.readFileSync` or similar file system APIs.
