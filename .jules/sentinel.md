## 2026-06-04 - Client-side API Key Exposure\n**Vulnerability:** OpenAI API Key exposed on client side and instantiated directly in client bundle with dangerouslyAllowBrowser: true.\n**Learning:** Next.js applications shouldn't instantiate services requiring secret keys on the client-side.\n**Prevention:** Make API calls via an internal Next.js API route (/api/...) rather than directly to third-party services from the client. Never use dangerouslyAllowBrowser for production apps.
## 2026-06-04 - Path Traversal Vulnerability\n**Vulnerability:** The API route `app/api/try-on/route.ts` used `path.join` with unsanitized user input `localPath` to read local files, allowing for path traversal attacks.\n**Learning:** When resolving local paths based on user input, always use `path.resolve` and verify that the resulting absolute path strictly starts with the intended base directory (using `path.sep` to prevent partial matches).\n**Prevention:** Sanitize user input before passing it to `path.join` or `path.resolve`, and use strict base directory checking.
