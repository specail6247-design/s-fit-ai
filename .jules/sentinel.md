## 2024-07-16 - [CRITICAL] Fix Path Traversal in Local File to Data URI Conversion\n**Vulnerability:** Found a critical path traversal vulnerability in `app/api/try-on/route.ts` where unsanitized local path inputs were joined with the public directory via `path.join`, allowing out-of-bounds local file reading using `../../` sequences.\n**Learning:** In Node.js server routes, relying solely on path.join without strict boundary checking leaves APIs susceptible to arbitrary local file read if external strings are resolved to local assets.\n**Prevention:** Use `path.resolve` relative to the intended base directory and explicitly enforce strict directory scope containment by checking if the resulting absolute path `.startsWith(baseDirectory + path.sep)`.
