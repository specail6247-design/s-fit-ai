## 2024-05-18 - Path Traversal Vulnerability in Image Loading
**Vulnerability:** Path Traversal vulnerability found in `app/api/try-on/route.ts` where user-supplied input (`garmentImageUrl`) was used to construct file paths via `path.join`. This allowed arbitrary files to be read from the filesystem outside the intended `public` directory (e.g., using paths like `/../../../../.env`).
**Learning:** Using `path.join()` directly with user-supplied input allows directory traversal attacks (`../`) because it simply joins string segments without ensuring the resulting path is contained within the intended base directory.
**Prevention:** To prevent Path Traversal vulnerabilities when reading files based on user input, avoid using `path.join()`. Instead, use `path.resolve()` to determine the absolute paths of both the base directory and the target file, and explicitly validate that the resolved target path strictly starts with the intended base directory including the trailing separator (e.g., `if (!absolutePath.startsWith(publicDir + path.sep)) { return null; }`).
