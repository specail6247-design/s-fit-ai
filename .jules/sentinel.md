## 2024-05-18 - Path Traversal Vulnerability in localFileToDataUri
**Vulnerability:** A path traversal vulnerability existed in `app/api/try-on/route.ts` where `path.join` was used to construct an absolute path using a user-provided relative path (`garmentImageUrl`), allowing users to read arbitrary files from the server's filesystem by passing a path starting with `//` and containing traversal sequences (e.g., `//../../../../etc/passwd`).
**Learning:** `path.join` is not safe enough to prevent path traversal when dealing with user input because it resolves `..` segments. When verifying path boundaries in Node.js to prevent path traversal (e.g., using `absolutePath.startsWith(publicDir)`), simply checking if the resolved path starts with the base directory is insufficient, as it's vulnerable to directory name spoofing attacks where a sibling directory shares the same prefix.
**Prevention:** Always append `path.sep` to the base directory string (e.g., `publicDir + path.sep`) when verifying path boundaries. Ensure `path.resolve` is used to normalize paths before boundary checks.
