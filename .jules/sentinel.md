## 2024-04-11 - Path Traversal Vulnerability in API Routes
**Vulnerability:** Found a path traversal vulnerability in `app/api/try-on/route.ts` where unsanitized user input (`garmentImageUrl`) was appended to the base directory path using `path.join()`. This could allow attackers to traverse the file system outside of the intended `public/` directory (e.g., passing `../../../etc/passwd` or similar relative traversal constructs) because `path.join()` normalizes the dots without strictly constraining them.
**Learning:** In Node.js/Next.js API routes, using `path.join()` alone with unsanitized paths is dangerous. If the path string starts with multiple `../` after the leading slash is stripped, `path.join` resolves it upwards, circumventing the intended directory.
**Prevention:** Always use `path.resolve()` with a known absolute base directory. Crucially, after resolution, strictly verify that the resulting `absolutePath` either exactly matches the base directory or strictly begins with `baseDir + path.sep` (e.g., `absolutePath.startsWith(publicDir + path.sep)`).
